# Phase 0 - Input Needed From the Team
You do **not** need to complete `project-intake-template.md`. That template is for KAppHelper
maintainers to normalise project facts after gathering them from the registry, project overview,
meeting captures, repositories, and deployment configuration.

This folder contains only the facts that cannot be safely discovered from those sources. Fill a
field with a direct value, a safe link, or `needs verification`; do not include passwords, tokens,
keystores, certificates, or private keys.

Current pilot: TCS and TWPC mobile release profiles.
